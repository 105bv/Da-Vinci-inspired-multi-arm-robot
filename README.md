# Da Vinci-Inspired Multi-Arm Robotic System

## Project Overview

A research project developing an intelligent multi-arm robotic system for manufacturing applications.

The software system will be developed and tested using ROS 2 and Gazebo before deployment on a Raspberry Pi and integration with physical robotic arms.

## Development Environment

* Ubuntu 24.04 (WSL2)
* ROS 2 Jazzy
* Gazebo Harmonic
* ros2_control
* Python / C++
